# Clean Flash 34.0.0.376 ReleaseOnly

这是面向普通用户和旧式 ActiveX 程序的社区维护版。

## 主要变化

- Flash 组件更新到 Windows 34.0.0.376；
- 移除 Debug 安装选择；
- 安装逻辑强制使用 Release 组件；
- 保留旧 Flash、Flash Center、服务、注册表和标准目录的完整清理；
- 支持 ActiveX、NPAPI、PPAPI 与独立播放器；
- 附带 SHA-256 校验文件和公开构建流程。

## 已测试的发布文件

本 Release 发布的是已经完成真实 Windows 运行测试的同一个 Actions Artifact，
不是测试后重新编译的替代文件：

```text
CleanFlash_34.0.0.376_ReleaseOnly_Installer.exe
SHA-256: dae566c0f9618558d3bcc1bb600eaf1a93d9bd2a1c179cc0b74df6fb4ef309f4
```

验证环境：

- Windows 10 专业版 22H2；
- 64 位操作系统，系统内部版本 19045.5912；
- 32 位 ActiveX 旧式宿主程序；
- 安装及目标程序运行测试未发现问题，未再次出现原访问冲突。

此结果不能自动证明 NPAPI、PPAPI、Standalone、Windows 7 或 Windows 11
均已完成独立运行测试。

## 解决的典型问题

如果旧程序报错：

```text
Access violation ... in module 'Flash32_34_0_0_330.ocx'
Read of address 0000000C
```

或者更新到 34.0.0.376 Debug OCX 后仍然出现相同读取地址，本版本会清理旧安装并改装
34.0.0.376 Release OCX。详细证据与验证方法见仓库中的
`docs/TROUBLESHOOTING.zh-CN.md`。

## 安全提醒

Flash 已停止全球支持。仅运行可信内容，优先在离线或隔离环境使用。此社区项目与 Adobe、
重橙网络及原 Clean Flash 维护者均无隶属关系。

安装前请核对同一 Release 中的 `SHA256SUMS.txt`。
